**Two traps worth remembering.**
- **`text-base` is a COLOUR in this project, not a font size.** `@theme` defines
  `--color-base`, so Tailwind v4 compiles `.text-base{color:var(--color-base)}`
  (#FBFAF6, near-white). It silently painted the band's sub-headline invisible.
  It was also latent in `Button.astro`, harmless only because every Button is the
  primary variant whose `text-inverse` is the same hex - a secondary/ghost button
  would have rendered near-white text on a light background. Both now use
  `text-[1rem]`. **Never write `text-base` in this repo.**
- **Reading a file in Python text mode silently converts CRLF -> LF.** These
  files are CRLF; four got flattened, which would have shown as "every line
  changed". Always `io.open(..., newline="")` for both read and write, and check
  `b.count(b"\n") - b.count(b"\r\n") == 0` afterwards.
