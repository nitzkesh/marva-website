Generic content surface — used for the audience-fork cards (advertisers/publishers) and the order-form shell.

```jsx
<Card accent="var(--marva-sage)">
  <h3>למפרסמים</h3>
  <p>בוחרים את הקהל, אנחנו מחלקים.</p>
</Card>
```

`accent` draws a 4px top stripe in a brand color to differentiate two adjacent cards (e.g. sage for advertisers, sky for publishers) without resorting to a left-border-accent pattern.
