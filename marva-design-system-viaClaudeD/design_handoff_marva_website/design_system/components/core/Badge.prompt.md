Small pill label — used for the personality tags (Refreshing/Smart/Urban) and for distribution-point chips (beach, promenade, event names) on dark sections.

```jsx
<Badge tone="sage">Refreshing</Badge>
<Badge tone="outline">טיילת תל אביב</Badge>
```

Tones: `sage`/`sky`/`sand` (light fills, black text) for use on light backgrounds; `outline` (transparent, off-white border) for use on the dark ink section.
